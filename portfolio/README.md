# Personal Portfolio

> 🔗 **Live Preview:** [codsoft-eta-five.vercel.app](https://portfolio-rachitsaini.vercel.app/)

Welcome to my personal portfolio! This project is a digital resume that showcases my technical skills, educational background, and featured projects as a MERN Stack Developer. 

## 🚀 Overview

This portfolio was originally built using Vanilla HTML, CSS, and JavaScript. It has since been **fully migrated to React (TypeScript) and Tailwind CSS** to ensure a modern, modular, and maintainable architecture, while keeping the exact same stunning visual design, layout, and complex keyframe animations.

## ✨ Features

- **Modern Tech Stack**: Rebuilt entirely with React, TypeScript, and Vite.
- **Tailwind CSS Utility Styling**: Layouts, typography, and spacing are handled by Tailwind CSS for rapid styling.
- **Complex Custom Animations**: Retains intricate CSS keyframe animations (Neural networks, Code Rain, Particle generation, Geometric floating shapes, Wave gradients) to deliver a highly interactive experience.
- **Modular Components**: Divided into logical sections like `Hero`, `About`, `Skills`, `Projects`, `Experience`, and `Contact`.
- **Intersection Observer Hooks**: Features scroll-based fade-in effects implemented natively with React Hooks (`useScrollAnimation`).
- **Fully Responsive**: Adapts seamlessly from mobile screens to 4k displays.

## 🛠️ Built With

- **React 19**
- **TypeScript**
- **Tailwind CSS v4**
- **Vite**
- **CSS Custom Properties & Keyframes**

## 💻 Getting Started

To run this project locally on your machine, follow these steps:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Clone the repository** (if applicable) or navigate to the project directory:
   ```bash
   cd portfolio
   ```

2. **Install the dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Open your browser** and navigate to:
   ```
   http://localhost:5173
   ```
